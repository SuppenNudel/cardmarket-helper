# Cardmarket Helper

[Install from Firefox Add-ons](https://addons.mozilla.org/en/firefox/addon/cardmarket-helper/)

Cardmarket Helper adds card previews, collection-aware listing assistance, price comparisons, and order reminders to Cardmarket.

## Features

- Preview card images in place of camera placeholders.
- Import a ManaBox collection for ownership-aware Magic Singles tools and listing assistance.
- Compare offer prices and printing data, with optional Magic format filtering.
- See price statistics on wants lists and Shopping Wizard results.
- Mark sales orders as packed and sync collection data with Google Drive.

See the [user guide](docs/user-guide.md) for details and screenshots.
